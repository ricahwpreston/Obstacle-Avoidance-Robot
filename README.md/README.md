# Obstacle Avoidance Robot

Arduino-based obstacle avoidance robot developed for our Embedded Systems course.

## Current Development

This project is being built subsystem by subsystem.

### Week 6 - Parallel Input and Output
- Motor control
- Direct register manipulation
- Forward, reverse, left, right, and stop movement

### Week 7 - Serial Communication
- HC-SR04 ultrasonic sensor
- UART communication
- Serial Monitor
- Obstacle status reporting

### Week 8 - Interrupts
- External interrupts
- Polling vs interrupt
- Timer interrupts
- Periodic obstacle scanning

## Final Goal

The final robot will integrate:

Sensor input → decision making → motor control → obstacle avoidance
