# Obstacle Avoidance Robot

Arduino-based obstacle avoidance robot developed for our Embedded Systems project.

## Current Development

- Week 6 - Parallel Input and Output
- Week 7 - Serial Communication
- Week 8 - External and Timer Interrupts

## Development Approach

The robot is being developed subsystem by subsystem. Each Embedded Systems topic is first demonstrated using the actual robot components before everything is integrated into the final autonomous obstacle avoidance robot.
