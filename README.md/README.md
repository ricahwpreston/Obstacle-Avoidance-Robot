# Obstacle Avoidance Robot

Arduino-based obstacle avoidance robot developed for our Embedded Systems course.

## Project Overview

This project is being developed gradually by building and testing the robot subsystem by subsystem.

For the current classroom demonstrations, we are focusing on three Embedded Systems topics:

- Week 6 - Parallel Input and Output
- Week 7 - Serial Communication
- Week 8 - External and Timer Interrupts

## Development Stages

### Week 6 - Drive System and Parallel I/O

The first stage focuses on the actual motor subsystem of the robot.

We will demonstrate:

- Motor control
- Forward movement
- Reverse movement
- Left turn
- Right turn
- Stop
- Direct I/O and register manipulation

### Week 7 - Ultrasonic Sensing and Serial Communication

The second stage adds the ultrasonic sensor.

We will demonstrate:

- HC-SR04 distance measurement
- UART communication
- Serial Monitor
- PATH CLEAR status
- OBSTACLE DETECTED status

### Week 8 - Interrupts and Timing

The third stage focuses on event-driven and periodic robot behavior.

We will demonstrate:

- External interrupts
- Polling vs. interrupts
- Timer interrupts
- Periodic obstacle scanning

## Final Project Goal

After the individual subsystems are tested, they will be integrated into the complete obstacle avoidance robot.

The final process will follow:

Sensor Input → Distance Measurement → Decision Making → Motor Control → Obstacle Avoidance
